# Mob Write 四阶段路线图

沿用已有仓库和实现推进，不重新维护一份源码。下表区分本轮候选验收与仍需后续证据的事项；完成一个阶段不代表已正式发版。

| 阶段 | 要交付什么 | 怎样验收 | 当前状态与未完成项 |
| --- | --- | --- | --- |
| 1. 定义宪法 | 简短原则、范围和四阶段计划 | 每条原则能指导具体写作或工程选择；明确事实、语言、私密数据、授权与价值验证边界 | 宪法与路线已写入本候选；后续变化应说明理由 |
| 2. 对齐当前实现 | 一个 `mob-write` 入口，小核心、场景增量与按需教学例 | 名称、描述、路由、包与文档一致；无旧名转接；例子不复制 canonical 规则；私密 profile 可选 | rc.3 已收敛为单入口并验证历史受管安装迁移；rc.4 优化核心与场景，新增 12 个合成教学例 |
| 3. 验证发现、加载和写作价值 | 隔离安装、新会话读取、与教学例不同的具体请求 | 分开核对源/包/安装/读取；检查事实、承诺、收件人语言和多读/漏读；保留原样输出与反例 | [rc.4 验收](rc4-validation.md)保留初始比较、确认与风险。[rc.5 有界核查](rc5-validation.md)区分原题歧义与明确边界：4 个新题双方符合约束，旧日期题仍有歧义，未证明可重复改善；未读例库，真实反馈和稳定性待验证 |
| 4. 做好安装升级与开源发行 | 可复现公开包、候选安装、迁移说明、CI 与 draft PR | 从公开远端取得同一版本，隔离安装/升级与 CI 产物一致；许可证完整，历史可恢复 | rc.5 的 48 项结构检查、源/包/安装字节对照及实际 rc.4 原安装器到 rc.5 的隔离升级通过；保留更早升级证据。当前提交的 CI 见 [PR #2](https://github.com/hotmob/mob-write/pull/2)。合并及正式 release 待另作决定 |

## 本轮不做

- 不修改当前全局 skill、私人 profile 或其他项目，也不发送消息和控制社交账号。
- 不复制成第二个 canonical 仓库，不删除历史版本或复用旧仓库名破坏重定向；旧活动入口迁移须可恢复。
- 不新增遥测、第三方推广、自动学习私人素材或平台基础设施。
- 不承诺写作提升百分比、真实使用人数或互动增长；现有合成对照不能支持这些结论。

后续优先解决观察到的加载混用、无用播报或事实失真问题，再考虑新增场景。真实任务反馈应由贡献者主动提供并去除私人信息；可使用本地方法，不要求上传自己的文字。验收证据见 [评估](evaluation.md)，安装边界见 [迁移](migration.md)。
