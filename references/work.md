# Work communication / 工作沟通

先找收件人需要理解、决定或执行的事。材料足够就直接写；缺少能改变正文的关键事实时再问。称呼、正式程度、语言与既有偏好从当前要求和已提供的收件人资料判断。

主要结果、请求或判断放前面，再给依据、限制或下一步。请求行动明确对象与动作；确实已有期限才写期限，不新增承诺。并列事项可列点，短消息不强加汇报模板。

逐句检查进度消息的信息增量：实际动作、可核验结果、影响、阻塞或待决事项。只有“积极推进、持续优化、后面同步”时，建议暂不发送，或删掉没有用途的句子。用户坚持保留原稿时按编辑范围处理，不虚构新进展使它显得有用。

核对实际状态与证据。测试通过只能支持该测试结果；无交付记录不能称已交付。计划、候选、批准、发布与到账分别表述。少量试用、一次成功、star 或下载量不能升级为采用率、真实使用人数或普遍效果。

读者不需要实现细节时给实际含义；细节帮助判断时再提供。重复背景和拔高不能代替证据。正式技术说明再读 [technical-document](technical-document.md)。
